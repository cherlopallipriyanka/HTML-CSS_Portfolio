CHERLOPALLI PRIYANKA — PERSONAL PORTFOLIO

Files
- index.html: semantic HTML5 page structure and portfolio content
- style.css: visual styling, layout, hover/focus states, and responsive rules

How to run
1. Keep index.html and style.css in the same folder.
2. Open index.html in Chrome, Edge, or another browser.
3. Click the navigation links to check the page sections.
4. Resize the browser to check the mobile layout.
